# VAT v0.1.0

第一个公开版本。VAT 是一款本地桌面剪辑工作台：从选题到成片，把策划、文案、分镜、选材、配音、字幕、导出串成一条流水线，中间任何一步都能停下来改，改完只重跑那一步。

## 下载

| 文件 | 适用 | 说明 |
| --- | --- | --- |
| `VAT.exe` | Windows 10/11 x64 | 单文件，双击即可运行，无需安装 Python |
| `VAT-source.zip` | 任意系统 | 源码与文档，供查看与自行构建 |
| `SHA256SUMS.txt` | 全部 | 校验值，下载后请核对 |

macOS 与 Linux 的构建在 CI 中逐次产出为工作流附件（Actions 页面的 Artifacts），本页暂不固定提供。

## 运行前需要

1. **FFmpeg 与 FFprobe**：导出视频必需，需包含 H.264、AAC 与 subtitles 滤镜。把所在目录加入 `PATH`，或在「设置 → 文件与工具」里指定目录。
2. **一个模型通道**：Codex CLI、DeepSeek Harness，或任一 OpenAI 兼容 / Anthropic / Gemini 接口；本机 Ollama、LM Studio 也可。没有模型也能手工编辑与预览，只是 AI 功能不可用。
3. **中文字体**：非 Windows 系统请安装 Noto Sans CJK 一类字体，否则字幕可能显示为方块。

## 首次运行可能被拦截

本版未做代码签名。Windows 可能弹出「Windows 已保护你的电脑」或杀毒软件误报——单文件打包程序较常见。

- 确认文件来自本页 Release，再用 `SHA256SUMS.txt` 核对哈希；
- 核对无误后，可点「更多信息 → 仍要运行」；
- 校验值不一致请勿运行，直接删除并反馈。

## 数据在哪儿

- 项目、素材索引、缓存与成片保存在本机工作区，Windows 默认在 `%LOCALAPPDATA%\分镜工作台`。
- 软件本身没有服务器，作者不收集任何数据。
- 你配置的 AI 服务会收到你主动发送的文案、台词、文件名等内容，由对应服务商按其条款处理。详见 README 的「数据会去哪儿」。
- 卸载：删除 `VAT.exe`，再删除上面的工作区目录即可。

## 已知问题

- 成片固定 720p / 25 fps，暂不支持自定义分辨率与帧率。
- 抖音选题需要 Ego Lite，并依赖页面已登录状态。
- 本版仅经作者本机与 CI 验证，未大范围外部试用。
