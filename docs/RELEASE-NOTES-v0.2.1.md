# VAT v0.2.1

这版可以决定 AI 参考素材库的程度。打开「一键生成视频」，在「素材库参考程度」里选择一档：

| 档位 | AI 怎样参考素材库 |
| --- | --- |
| 自主创作（低） | 先独立构思场景和动作，再借鉴素材的构图、色彩或表现手法；需要实证时仍可使用原素材。 |
| 平衡参考（中，默认） | 先定画面，再挑选能帮助表达的素材，与原创设计结合。 |
| 高度参考（高） | 优先采用贴题的录屏、图片、底图和动效，保留有用细节，再用原创动作补足。 |

三档分别使用不同提示词，应用于策划、分镜、选材与原创动效。素材库不是创作边界：每档都可跳过无关素材，库为空也能制作原创场景和动作。「动效提示词」仍单独控制动画的细致程度。

## 其他更新

- 一键生成支持 15 秒及以上的时长。可选择竖屏 9∶16、竖屏 3∶4、横屏 16∶9 或方形 1∶1，策划到成片沿用所选画幅。
- 选材与动效会验证生成的动画是否有可见运动。可在「设置 → 更新日志」离线查看完整版本记录。

## 下载和升级

| 文件 | 用途 |
| --- | --- |
| `VAT.exe` | Windows x64 单文件程序，无需安装 Python。 |
| `VAT-source.zip` | 源码、说明、许可和测试，用于查看与自行构建。 |
| `SHA256SUMS.txt` | 发布文件的 SHA-256 校验值。可用 PowerShell 的 `Get-FileHash .\VAT.exe -Algorithm SHA256` 核对。 |

升级前先关闭 VAT，再替换旧程序。无需移动工作区或重新导入项目，旧项目缺少参考档位时按平衡参考处理。续做仅影响未完成的环节，已经生成原创动效的项目沿用原档。要用新档从头策划，可点「另开一期」。

一键生成需要配置可用的 AI 模型和配音通道，视频导出需要 FFmpeg 和 FFprobe。完整操作见仓库的《使用说明》和《更新日志》。
