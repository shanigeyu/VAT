# VAT v0.2.2

这版换了一套更好看的默认界面「深栏晨光」：深墨色侧栏、冷白工作区、圆角白卡片，窗口标题栏与侧栏同色。打开软件后直接进入「一键生成视频」。

## 界面更新

- **新默认主题「深栏晨光」**：侧栏改成深墨色，选中项用提亮的重点色指示条；工作区为冷白底，卡片、按钮和输入框为圆角，表格去掉外框。松绿、靛蓝、紫藤、琥珀四种主题配色都可搭配。
- **顶栏显示版本号**：右上角的小标签显示当前版本。
- **启动页改为「一键生成视频」**：与侧栏第一项一致，打开即可开始制作。
- **旧版默认主题自动换新**：此前用默认「简约工作台」的用户，升级后会自动切换一次到新主题；想换回，到「设置 → 外观与语言 → 工作台主题」选择即可，之后不会再被改动。选过「柔和纸白」或「经典工作台」的用户保持原样。

## 下载和升级

| 文件 | 用途 |
| --- | --- |
| `VAT.exe` | Windows x64 单文件程序，无需安装 Python。 |
| `VAT-source.zip` | 源码、说明、许可和测试，用于查看与自行构建。 |
| `SHA256SUMS.txt` | 发布文件的 SHA-256 校验值。可用 PowerShell 的 `Get-FileHash .\VAT.exe -Algorithm SHA256` 核对。 |

升级前先关闭 VAT，再替换旧程序。无需移动工作区或重新导入项目。

一键生成需要配置可用的 AI 模型和配音通道，视频导出需要 FFmpeg 和 FFprobe。完整操作见仓库的《使用说明》和《更新日志》。
