# VAT v0.1.2

修掉「生成到三分钟就被停掉」这一个问题：用 DeepSeek Harness 生成文案、分镜或选材，超过 180 秒就会被判超时，整个任务当场结束。

## 这一版修了什么

- **生成不再有 180 秒硬上限**。以前调用本机 DeepSeek Harness 生成，固定 180 秒没返回就报「DSH 在 180 秒内没有完成，已停止本次任务」。分镜一多、资料一长，基本都会撞上这条线，换哪个模型都一样。现在生成调用不再设总时长：任务只在 Harness 返回、你点「中断并保存」或关闭窗口时结束。
- **中断照旧即时生效**。生成途中点「中断并保存」，仍会结束 Harness 的进程树，已完成的环节照常保存；重开项目点「继续制作」不会重跑这些环节。
- **配置探测仍快速失败**。读取 Harness 配置（`--dump-config`）保留 20 秒超时，路径填错或安装损坏时立刻报错，不会让人对着空进度条干等。

版本号显示在「设置」页右上角，这一版起是 `v0.1.2`。升级只需替换 `VAT.exe`，工作区和已有项目都不用动。

## 运行前需要

1. **FFmpeg 与 FFprobe**：导出视频必需，需包含 H.264、AAC 与 subtitles 滤镜。把所在目录加入 `PATH`，或在「设置 → 文件与工具」里指定目录。
2. **一个模型通道**：Codex CLI、DeepSeek Harness，或任一 OpenAI 兼容 / Anthropic / Gemini 接口；本机 Ollama、LM Studio 也可。没有模型也能手工编辑与预览，只是 AI 功能不可用。
3. **中文字体**：非 Windows 系统请安装 Noto Sans CJK 一类字体，否则字幕可能显示为方块。

## 首次运行可能被拦截

本版未做代码签名。Windows 可能弹出「Windows 已保护你的电脑」或杀毒软件误报——单文件打包程序较常见。

- 确认文件来自 Release 页面，再用 `SHA256SUMS.txt` 核对哈希；
- 核对无误后，可点「更多信息 → 仍要运行」；
- 校验值不一致请勿运行，直接删除并反馈。

## 遇到问题

先看 `%LOCALAPPDATA%\VAT Studio\logs\vat.log`，里面记了启动、关闭和未捕获的异常。反馈时附上这个文件和复现步骤。生成卡住时可以直接点「中断并保存」，不会丢掉已完成的环节。
