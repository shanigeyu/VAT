# VAT v0.3.0

这版把「能看见、能对话」带进了制作流程：分镜编排能直接看每一镜的画面并单独修改，封面页可以自己挑生图模型，四个制作步骤都多了一个「AI 对话」框，配音也能告诉 AI 想要的情感。

## 新功能

- **分镜画面预览**：「分镜编排」右侧显示所选镜头的合成静帧（主题、主体、原创动效、动效叠层）。点「编辑此镜」或「AI 修改此镜」即可单独改这一镜。
- **分镜画面总览**：一屏查看全部镜头画面，点任一张直接修改那一镜。
- **封面生图模型**：「封面制作」新增「生图模型」一栏，可直接选择 Codex CLI 或支持生图的 API；新增「画面要求」，附加到三张底图的绘制提示。
- **AI 对话**：「文案定稿」「分镜编排」「音频制作」「封面制作」右上角新增「AI 对话」，用本步骤选定的模型直接对话修改当前内容。AI 的改动先列出，点「应用改动」才写回；对话记录按项目和页面保存。
- **配音情感与语气**：「音频制作 → 文案声」可填写或通过对话整理配音情感。语音 API（OpenAI 兼容）随请求发送 `instructions`，音频大模型写入朗读提示。GPT-SoVITS 与 ElevenLabs 暂不使用。修改后重新合成即生效。

## 下载和升级

| 文件 | 用途 |
| --- | --- |
| `VAT.exe` | Windows x64 单文件程序，无需安装 Python。 |
| `VAT-source.zip` | 源码、说明、许可和测试，用于查看与自行构建。 |
| `SHA256SUMS.txt` | 发布文件的 SHA-256 校验值。可用 PowerShell 的 `Get-FileHash .\VAT.exe -Algorithm SHA256` 核对。 |

升级前先关闭 VAT，再替换旧程序。无需移动工作区或重新导入项目。

AI 对话、生图和配音需要先配置可用的模型或语音服务，视频导出需要 FFmpeg 和 FFprobe。完整操作见仓库的《使用说明》和《更新日志》。
