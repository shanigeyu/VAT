# VAT v0.1.1

修掉「打不开也关不上」这一类问题：窗口关不掉、进程留在后台，下次打开只提示工作区被占用；启动失败时窗口直接消失，什么也不说。这一版把启动和关闭这两条路都补上了，同时带上 v0.1.0 之后做的新功能。

## 这一版修了什么

- **关窗口一定会退出**。以前有任务在跑时点 X，程序只发一次中断就返回；任务卡在网络请求或外部进程上，窗口和进程就都留在后台，工作区锁也一直被占着——于是下次再打开只会看到「此工作区已打开」。现在保存后会等任务停下，几秒内没停就强制关闭。
- **再次打开会切回已有窗口**。工作区已被另一个 VAT 占用时，自动把那个窗口从最小化恢复到前台；确实找不到窗口，才提示去任务管理器结束 `VAT.exe`。
- **启动失败不再静默**。打包后的程序没有控制台，以前启动出错窗口会直接消失。现在错误写进 `%LOCALAPPDATA%\VAT Studio\logs\vat.log`，并弹窗说明原因；窗口位置跑到屏幕外或停在最小化状态时，也会自动摆回屏幕中央。
- **弹窗不再锁死主界面**。主窗口最小化时系统会把弹窗一起藏起来，但抓取还留在弹窗上，恢复后整个界面点不动。现在弹窗不可见时释放抓取，重新显示时再拿回来。
- **任务窗口意外消失不再卡住后续操作**，教程与自动保存写入失败也只记日志，不再挡住关闭。

## 新增

- **封面制作**：9∶16、3∶4、16∶9 三种画幅，黑金冲击、简约大字、暗黑科技、暖色纪实四种风格；按标题与风格一次生成三张底图供挑选，也可从成片或样片取帧。
- **新手教程**：启动时先讲运行环境，再讲模型、agent 与本地语音怎么配；可永久关闭，也能从「设置 → 使用指南」再打开。
- **复制软件位置**：一键把程序、配置和工作区路径复制到剪贴板，直接粘给 agent 让它替你配置。

## 运行前需要

1. **FFmpeg 与 FFprobe**：导出视频必需，需包含 H.264、AAC 与 subtitles 滤镜。把所在目录加入 `PATH`，或在「设置 → 文件与工具」里指定目录。
2. **一个模型通道**：Codex CLI、DeepSeek Harness，或任一 OpenAI 兼容 / Anthropic / Gemini 接口；本机 Ollama、LM Studio 也可。没有模型也能手工编辑与预览，只是 AI 功能不可用。
3. **中文字体**：非 Windows 系统请安装 Noto Sans CJK 一类字体，否则字幕可能显示为方块。

## 首次运行可能被拦截

本版未做代码签名。Windows 可能弹出「Windows 已保护你的电脑」或杀毒软件误报——单文件打包程序较常见。

- 确认文件来自 Release 页面，再用 `SHA256SUMS.txt` 核对哈希；
- 核对无误后，可点「更多信息 → 仍要运行」；
- 校验值不一致请勿运行，直接删除并反馈。

## 遇到问题

先看 `%LOCALAPPDATA%\VAT Studio\logs\vat.log`，里面记了启动、关闭和未捕获的异常。反馈时附上这个文件和复现步骤。
